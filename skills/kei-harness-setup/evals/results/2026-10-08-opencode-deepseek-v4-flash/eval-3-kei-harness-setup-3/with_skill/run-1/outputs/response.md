Windsurf isn't in the supported harnesses list. Per the skill: *"Any other harness is unsupported and is denied until an adapter is explicitly registered. Do not improvise one."*

The currently supported coding-agent harnesses are: **Claude Code, Codex, OpenCode, Pi, and Cursor** (with caveats). Windsurf would need its own adapter registered with Kei before it can be governed.

That said, if you check the console at **Agents →** there may be a Windsurf card with a setup prompt if they've since added it. Want me to look it up?
